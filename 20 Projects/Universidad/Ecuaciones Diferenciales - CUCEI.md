# Course: Ecuaciones Diferenciales

## Course Info
- **Schedule:** Lunes y Miércoles, 11:00 AM - 1:00 PM
- **NRC / Clave:** 197380 / IL347 — 8 créditos
- **Grade:**

## Learning Objectives
> Al finalizar este curso, seré capaz de resolver ecuaciones diferenciales de primer orden y de orden superior, y de usar la Transformada de Laplace para resolver problemas de valor inicial.
1. Resolver ecuaciones diferenciales de primer orden (variables separables, lineales, exactas)
2. Resolver ecuaciones diferenciales de orden superior (coeficientes constantes, variación de parámetros)
3. Aplicar la Transformada de Laplace para resolver ecuaciones diferenciales

## Topics & Modules
### Unidad 1: Ecuaciones de Primer Orden — Semanas 0-2 (17 sep - 4 oct)
- [ ] Variables separables
- [ ] Ecuaciones lineales de primer orden
- [ ] Ecuaciones exactas
- [ ] Aplicaciones (crecimiento/decaimiento, mezclas)

### Unidad 2: Ecuaciones de Orden Superior — Semanas 3-5 (5-25 oct)
- [ ] Ecuaciones lineales homogéneas de coeficientes constantes
- [ ] Ecuaciones lineales no homogéneas (coeficientes indeterminados, variación de parámetros)
- [ ] Aplicaciones (sistemas masa-resorte, circuitos)

- [ ] Definición y propiedades de la Transformada de Laplace
- [ ] Transformada inversa
- [ ] Resolver ecuaciones diferenciales usando Laplace
